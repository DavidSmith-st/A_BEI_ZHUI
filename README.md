# 运动目标控制与自动追踪系统 — 红色云台控制器

> STM32F407ZGTx / 双轴 PD42S1 / 裸机轮询 / USART1 JSON / 五按键控制

## 当前功能

红色云台提供两种工作模式：

1. **本地模式**：STM32直接运行屏幕中心 0.5m × 0.5m 固定正方形，不需要摄像头。
2. **追踪模式**：等待视觉发送A4靶纸4个顶点，收到后沿A4胶带顺时针走一圈。

两种模式都在走完一圈后回到软件零点并停止，不会自动重复运行。

## 硬件引脚

| 功能 | 引脚 |
|---|---|
| PAN STEP | PE11 / TIM1_CH2 |


| PAN DIR / EN | PE12 / PD13 |
| TILT STEP | PC6 / TIM8_CH1 |
| TILT DIR / EN | PD6 / PC7 |
| OLED SDA / SCL | PF0 / PF1 / I2C2 |
| 视觉 USART1 TX / RX | PA9 / PA10 |
| 回中 | PE4 / KEY_HOME |
| 启动 | PC0 / KEY_START |
| 暂停 | PC1 / KEY_PAUSE |
| 继续 | PC2 / KEY_RESUME |
| 模式切换 | PC3 / KEY_MODE |

五个按键均为内部上拉，按下接GND，低电平有效。按键由主循环轮询，并进行50ms软件消抖。

## 按键逻辑

| 按键 | 行为 |
|---|---|
| PE4 回中 | 立即终止当前任务并回到软件位置(0,0)，回中期间忽略视觉启动 |
| PC0 启动 | 本地模式直接运行固定正方形；追踪模式进入等待A4顶点状态 |
| PC1 暂停 | 停止STEP脉冲并保持EN有效，保存剩余脉冲和状态机位置 |
| PC2 继续 | 恢复暂停前的脉冲和轨迹状态 |
| PC3 模式 | 在“本地”和“追踪”之间切换；切换时停止当前任务并进入等待 |

按键处理优先级：回中 > 模式 > 暂停 > 继续 > 启动。

## 本地固定正方形

上电默认进入“本地”模式，但不会自动运动，必须按PC0启动。

轨迹：

```text
中心 → 左上 → 右上 → 右下 → 左下 → 左上 → 中心 → 完成
```

理论参数：云台距屏幕1m、屏幕方形边长500mm、16细分3200脉冲/圈。

```text
半边约125脉冲
整边约250脉冲
走边速度50Hz
整套动作约25秒
```

## A4视觉模式

1. 按PC3切换到“追踪”。
2. 按PC0启动，OLED显示等待。
3. 视觉发送有效的4顶点 `VISION_RESULT`。
4. 云台先到顶点0，再依次走顶点1、2、3、0，闭合四条边。
5. 回到软件零点并显示完成。

视觉协议：

```json
{"type":"VISION_RESULT","seq":1,"valid":1,"red_valid":1,"red_spot":{"x_mm":83.4,"y_mm":67.2},"vertex_count":4,"vertices_mm":[[-100,150],[100,150],[100,-150],[-100,-150]]}
```

- 坐标单位mm，屏幕中心为(0,0)，X右正、Y上正。
- 顶点顺序：左上、右上、右下、左下。
- 连续8帧 `valid=0`：停止并等待重新识别。
- 超过200ms没有 `VISION_RESULT`：停止，OLED显示故障。
- `red_valid=1` 表示本帧红点坐标可用于闭环；`red_valid=0` 时继续按顶点开环走，不使用 `(0,0)` 纠偏.
- 每条A4边按约12脉冲拆段，每段结束用红点实际位置与理想路径点计算反向修正.
- 闭环增益为1/2，单轴单次修正最大10脉冲，红点反馈超过160ms自动退回开环。

## OLED

```text
运动目标云台
本地  等待/运动/暂停/复位/完成
水平  red_spot.x_mm
俯仰  red_spot.y_mm
```

切换到A4模式时第二行左侧显示“追踪”。本地模式没有视觉坐标时第三、四行保持最近值或 `----`。

## 软件零点

软件零点是启动时步进位置计数器的(0,0)，没有机械限位开关。正式测试前必须先把激光对准屏幕中心，再上电。PE4回中是按累计脉冲回到这个软件零点，不等同于MCU的NRST复位键。

## 已知事项

- 屏幕固定正方形完全不依赖摄像头。
- A4走边已启用分段视觉闭环；红点丢失时自动退回顶点开环，红点恢复后继续纠偏。
- 俯仰轴在特定姿态抖动已通过无摄像头测试确认不是视觉数据引起，应继续检查驱动器PID、力矩、线束和机械负载。
- 绿光自动追踪属于另一套独立控制系统，本工程暂未实现。
